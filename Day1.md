## OOPS
OOPs is a programming paradigm. 
Pillars Of OOPS  ----
The main concepts of OOPs in Java are mentioned below:

- Inheritance
- Polymorphism
- Abstraction
- Encapsulation 

### Diffrent ways of creating Objects in Java
- Using new keyword
- Using new instance
- Using clone() method
- Using deserialization
- Using the newInstance() method of the Constructor class
